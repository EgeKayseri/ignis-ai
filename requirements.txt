#                  python-scikit-learn python-matplotlib python-scipy
#
# TensorFlow was REMOVED. There is no TensorFlow wheel for Python 3.14 and AMD's
# TensorFlow-ROCm path is Docker-only. The pipeline is PyTorch + ROCm, and the
# TFRecord archive is decoded by a pure-Python reader in src/tfrecord_to_npy.py.
